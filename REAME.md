# Random Password Generator 🔐

A Python-based random password generator created as part of my DecodeLabs Python Programming Internship.

## Features

- Generates random passwords based on the user's chosen length
- Includes uppercase and lowercase letters
- Includes numbers
- Includes special characters
- Ensures every password contains at least one number
- Ensures every password contains at least one special character
- Validates the password length
- Handles invalid input

## Technologies Used

- Python
- random module
- string module

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
py password_generator.py
5. Enter the desired password length.
